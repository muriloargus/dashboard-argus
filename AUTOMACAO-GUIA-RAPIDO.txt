📊 O QUE OS BOTS FAZEM:

🔍 BOT 1: Verificador de Storage
   └─ Valida que todos os dashboards têm IndexedDB + localStorage
   └─ Mostra capacidade de armazenamento

🚀 BOT 2: Migração para Supabase
   └─ Converte dashboards CSV antigos para Supabase em tempo real
   └─ Mantém compatibilidade com 2 formas de uso

🔄 BOT 3: Pipeline Principal (CSV → Supabase)
   └─ Sincroniza ativos, falhas, usuários, exceções
   └─ Detecta novos arquivos automaticamente
   └─ Valida dados antes de enviar

🌐 BOT 4: Geotab → Supabase
   └─ Sync de dados do PostgreSQL (MyGeotab Adapter)
   └─ Dados em tempo real
   └─ Incluído opcional
