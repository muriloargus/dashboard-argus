## 📊 COMPARAÇÃO: HTML vs Shiny

| Aspecto | HTML | Shiny ⭐ |
|---------|------|-------|
| **Desenvolvimento** | Manual HTML/JS | 100% R (mais fácil) |
| **Manutenção** | Arquivo por arquivo | Template reutilizável |
| **Dados** | localStorage (limitado) | Supabase + R reactivity |
| **Interatividade** | Chart.js | Plotly (mais interativo) |
| **Deploy** | GitHub Pages | Posit Cloud + GitHub Actions |
| **Mobile** | Às vezes | Totalmente responsivo |
| **Performance** | Bom | Excelente |
| **Scaling** | Difícil | Fácil com Shiny Server |

## 💡 DICAS

### Para Customizar Cores
Edit arquivo `app.R` e mude:
```r
COLOR_PRIMARY <- "#63a3d8"    # Azul
COLOR_SECONDARY <- "#e60000"   # Vermelho
COLOR_ACCENT <- "#FFD700"      # Ouro
```

### Para Mudar Título
Edit arquivo `app.R`:
```r
DASHBOARD_TITLE <- "MEU NOVO TÍTULO"
DASHBOARD_SUBTITLE <- "Meu subtítulo"
```

### Para Adicionar Novo Gráfico
1. Copie um gráfico existente
2. Mude X, Y e tipo
3. Adicione ao UI
4. Pronto!

## ⚠️ SE ALGO NÃO FUNCIONAR

### "R não está instalado"
→ Instale https://cran.r-project.org/bin/windows/

### "Pacotes não encontrados"
→ Run `SETUP-SHINY.bat` novamente

### "Port 3838 already in use"
→ Use outra porta: `shiny::runApp('...', port = 3839)`

### "Supabase não conecta"
→ Verifique credenciais no app.R

### "Deploy falha"
→ Verifique GitHub Secrets (Settings → Secrets)
