📚 Como Atualizar os Gráficos?

🔄 Os gráficos da Home são alimentados automaticamente

A página HOME puxa dados dos outros dashboards. Para atualizar:

  • Status da Frota: Vá em "Status Frota" → Carregue o CSV → Os dados aparecem aqui automaticamente
  • Motoristas: Vá em "Motoristas" → Carregue o CSV → Atualiza os dados
  • Ativos: Vá em "Ativos" → Carregue o CSV → Atualiza os dados
  • Usuários: Vá em "Usuários" → Carregue o CSV → Atualiza os dados

⚡ Sincronização em Tempo Real

Os dados são sincronizados a cada 5 segundos. Após carregar um CSV em qualquer dashboard, a HOME se atualiza automaticamente.

🔍 Filtrar Dados

  • Use o checkbox 🗑️ para remover "Sem cadastro" de todos os gráficos
  • Clique nos KPIs (Frota Online, Não Ativo, Offline) para filtrar apenas aquele status
  • Os gráficos se atualizam em tempo real

📍 O que cada Dashboard fornece:

  • Status Frota: Dados gerais da frota (status, região, fabricante, transportadora)
  • Usuários: Distribuição de usuários por transportadora e designação
  • Ativos: Informações técnicas dos veículos (tipo, câmbio, etc.)

💡 Dica: A HOME se atualiza automaticamente. Não é necessário recarregar a página!
