TROUBLESHOOTING - Se algo não funcionar
༺════════════════════════════════════════════════════════════════════════════════༻

  ❌ "Cliquei em RODAR-ORQUESTRADOR.bat mas não aconteceu nada"
     └─ [ ] Python está instalado? (python --version)
     └─ [ ] requirements.txt foi instalado? (pip list)
     └─ [ ] .env tem SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY?

  ❌ "Saída do BAT mostra ⚠️ warning mas não erro"
     └─ [ ] Is normal, se tiver ✅ no final, funcionou
     └─ [ ] Verifique dados no Supabase

  ❌ "GitHub Actions ainda falhando"
     └─ [ ] Atualize os 3 workflow files (.yml)
     └─ [ ] Verifique GitHub Secrets configurados
     └─ [ ] Clique no run que falhou e veja logs detalhados

  ❌ "PowerShell diz 'script not signed'"
     └─ [ ] Execute como admin
     └─ [ ] Ou: Set-ExecutionPolicy RemoteSigned

  ❌ "Dados não aparecem no dashboard"
     └─ [ ] Supabase tem dados? (SQL Editor → SELECT * FROM ativos)
     └─ [ ] Arquivo CSV tem formato correto?
     └─ [ ] Dashboard está acessando Supabase correto?
