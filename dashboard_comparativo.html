📚 Como Atualizar os Gráficos?

🔄 Passo 1: Carregar Novos Arquivos CSV

Os números dos gráficos são atualizados automaticamente quando você carrega arquivos CSV:

  • Motoristas CSV: Clique em "Motoristas CSV" e selecione o arquivo com dados de motoristas
  • Ativos CSV: Clique em "Ativos CSV" e selecione o arquivo com dados de ativos/veículos

🔤 Passo 2: Formato do CSV

Os arquivos devem conter as seguintes colunas:

Motoristas: Nome, CPF, NFC, Transportadora, Unidade
Ativos: Placa, Dispositivo, Transportadora, Unidade, Tipo, Fabricante

🔎 Passo 3: Filtrar (Opcional)

  • Use os dropdowns para filtrar por Transportadora e Unidade
  • Use o checkbox 🗑️ para remover "Sem cadastro" dos gráficos
  • Os gráficos se atualizam em tempo real

💾 Passo 4: Dados Salvos

Os dados são armazenados automaticamente no seu navegador (IndexedDB). Quando você volta ao dashboard, os últimos dados carregados aparecem novamente.

💡 Dica: Para atualizar completamente, carregue novamente os arquivos CSV. Os números se atualizam instantaneamente!
