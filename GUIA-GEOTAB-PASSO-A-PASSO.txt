PASSO 6: INTEGRAR COM SEU PIPELINE EXISTENTE
════════════════════════════════════════════════════════════════

Abra seu arquivo pipeline.py e adicione isto NO INÍCIO:

    import subprocess
    
    def sincronizar_geotab():
        """Executa sincronização Geotab antes do pipeline"""
        print("🚗 Sincronizando dados Geotab...")
        try:
            subprocess.run(['python', 'sync_geotab_to_supabase.py'], check=True)
            print("✅ Sincronização Geotab concluída!")
        except Exception as e:
            print(f"⚠️  Erro na sincronização Geotab: {e}")

No início da função main(), adicione:

    sincronizar_geotab()  # Sincroniza Geotab PRIMEIRO
    # Depois continua com o resto do seu pipeline

════════════════════════════════════════════════════════════════
TROUBLESHOOTING - ERROS COMUNS
════════════════════════════════════════════════════════════════

❌ "conexão recusada localhost:5432"
   → MyGeotab Adapter não está rodando
   → Instale e inicie o MyGeotab API Adapter primeiro

❌ "SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY não configuradas"
   → Seu .env não tem as chaves Supabase
   → Adicione SUPABASE_URL e SUPABASE_SERVICE_ROLE_KEY

❌ "Nenhum dispositivo encontrado no MyGeotab"
   → MyGeotab Adapter está vazio
   → Aguarde alguns minutos para dados chegarem

❌ "psycopg2 não encontrado"
   → Execute: pip install psycopg2-binary
