                                    FLUXO COMPLETO END-TO-END
═══════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

    A. ADICIONA DADOS
       ├─ Coloca CSV em ./input/
       └─ Ou dados chegam via Geotab API
                  ↓
    
    B. EXECUTA ORQUESTRADOR (Manual ou Automático)
       ├─ Local: Clique 2x em RODAR-ORQUESTRADOR.bat
       ├─ Automático: Windows Task Scheduler (PowerShell)
       └─ Nuvem: GitHub Actions (cronograma)
                  ↓
    
    C. BOTS PROCESSAM DADOS
       ├─ Bot 1: Verifica integridade (storage)
       ├─ Bot 2: Migra dashboards se necessário
       ├─ Bot 3: Envia CSV para Supabase
       └─ Bot 4: Sincroniza Geotab (opcional)
                  ↓
    
    D. COMMIT & PUSH (Automático)
       └─ Git commit: "🤖 Bot Argus: Sincronização automática"
          Git push: Para GitHub (se houver mudanças)
                  ↓
    
    E. DADOS LIVE NO SUPABASE
       └─ Tabelas atualizadas com novos registros
                  ↓
    
    F. DASHBOARDS CARREGAM AUTOMATICAMENTE
       └─ Abra qualquer dashboard
          └─ Clique "Carregar" ou refresque a página
             └─ Dados mais recentes carregam via IndexedDB ou Supabase
