🎨 FASE 4: CUSTOMIZAR CADA DASHBOARD (1 hora por dashboard)
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

Para cada dashboard, edite:

1. TITULO & DESCRIÇÃO (no topo de app.R)
   ```r
   DASHBOARD_TITLE <- "Dashboard Ativos"
   DASHBOARD_SUBTITLE <- "Rastreamento da Frota Ambev"
   DASHBOARD_ICON <- "truck"
   ```

2. DADOS (CSV ou Supabase)
   
   Para CSV:
   ```r
   DATA_SOURCE <- "local"
   CSV_PATH <- "../../../input/ativos_23-02.csv"
   ```
   
   Para Supabase:
   ```r
   DATA_SOURCE <- "supabase"
   SUPABASE_TABLE <- "ativos"
   ```

3. GRÁFICOS (funções output$chart_1, output$chart_2, etc)
   
   Edite as funções renderPlotly para plotar SEUS dados:
   
   ```r
   output$chart_1 <- renderPlotly({
     df <- dados()
     
     plot_ly(
       df,
       x = ~coluna_x,          # Mudar: qual coluna do seu CSV
       y = ~coluna_y,          # Mudar: qual coluna do seu CSV
       type = "scatter",       # Mudar: tipo de gráfico
       marker = list(color = PRIMARY_COLOR)
     )
   })
   ```

4. KPIs (caixas no topo)
   
   ```r
   output$kpi_1 <- renderInfoBox({
     df <- dados()
     
     infoBox(
       title = "Total de Registros",
       value = nrow(df),       # Mudar: pela métrica que quiser
       icon = icon("database"),
       color = "blue"
     )
   })
   ```

5. TESTAR LOCALMENTE
   ```r
   shiny::runApp("shiny/dashboard_ativos")
   ```

🚀 FASE 5: DEPLOY NO POSIT CLOUD (30 minutos)
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

1. Criar conta Posit Cloud
   └─ https://posit.cloud (use email/GitHub/Google)

2. Setup rsconnect
   
   No RStudio console:
   ```r
   install.packages("rsconnect")
   
   rsconnect::setAccountInfo(
     account = "seu_usuario",
     token = "seu_token",
     secret = "seu_secret"
   )
   ```
   
   (Copie token/secret do Posit Cloud → Account)

3. Deploy um dashboard
   
   ```r
   rsconnect::deployApp("shiny/dashboard_ativos")
   ```
   
   Aguarde... será publicado em: usuario.shinyapps.io/dashboard-ativos

4. Deploy dos 13 restantes
   
   ```r
   # Repetir para cada:
   rsconnect::deployApp("shiny/dashboard_motoristas")
   rsconnect::deployApp("shiny/dashboard_usuarios")
   # ... etc
   ```
   
   Ou automático com GitHub Actions (ver FASE 6)

🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════════════════════════════════════════════

❌ "Error: object 'dados' not found"
   └─ Solução: Verifique se load_data() retorna dataframe, não NULL

❌ "CSV not found"
   └─ Solução: Caminho CSV está correto? Arquivo existe em input/?

❌ "Supabase connection failed"
   └─ Solução: Variáveis SUPABASE_URL e KEY estão configuradas?
   
   ```r
   Sys.getenv("SUPABASE_URL")
   Sys.getenv("SUPABASE_SERVICE_ROLE_KEY")
   ```

❌ "Plotly não renderiza"
   └─ Solução: Dados vazios? Adicione:
   
   ```r
   if (nrow(df) == 0) return(plotly_empty(type = "scatter"))
   ```

❌ "RStudio não reconhece 'shiny'"
   └─ Solução: Reinstale:
   
   ```r
   install.packages("shiny", dependencies = TRUE)
   ```

❌ "rsconnect::deployApp() não encontra arquivo"
   └─ Solução: Certifique-se que struct está correto
   
   ```r
   setwd("seu_projeto")
   rsconnect::deployApp("shiny/nome_dashboard")
   ```
