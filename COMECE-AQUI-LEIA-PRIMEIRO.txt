P: Vou perder meus dados antigos?
R: Não! Os dados são sincronizados, não substituídos.
   Dados antigos e novos ficam no Supabase.

P: Preciso rodar pipeline.py toda vez?
R: Não! GitHub Actions faz isso automaticamente a cada 6 horas.
   Você roda só para testes ou quando quer sincronizar rápido.

P: E se eu colocasse arquivo .csv errado?
R: Sem problema! Delete de input/ e coloque o certo.
   Roda pipeline.py novamente.

P: Preciso de internet para os dashboards funcionarem?
R: SIM, se usar dados do Supabase (recomendado).
   NÃO, se usar dados locais (localStorage).

P: Posso parar de usar CSVs?
R: Sim! Depois que tudo estiver funcionando,
   você pode deletar os CSVs e usar só Supabase.
